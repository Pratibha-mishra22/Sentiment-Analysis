
# Sentiment Analysis using NLP

## Overview
This module analyzes customer feedback and classifies it as positive or negative using Natural Language Processing techniques.

## Objective
To understand customer sentiment and improve decision-making in financial systems.

## Technologies Used
- Python
- Scikit-learn
- TF-IDF Vectorization
- Logistic Regression

## Workflow
1. Data Preprocessing
2. Text Cleaning
3. Feature Extraction using TF-IDF
4. Model Training (Logistic Regression)
5. Evaluation

## Results
The model successfully classifies customer reviews with good accuracy.

## Files
- sentiment_analysis.ipynb
- sentiment_model.pkl
- vectorizer.pkl
